Grammaire "Classe et fonction des mots" Dans une phrase un mot a une classe grammaticale et une fonction.

Quelle que soit sa place dans la phrase le mot à toujours la même classe grammaticale.
Un nom restera un nom n'importe où dans la phrase.

En revanche, un même mot peut remplir plusieurs fonctions suivant la place qu'il occupe dans la phrase.
Un nom peut être le sujet d'une phrase ou le complément dans une autre phrase.

ex : Mon chien est gentil.
Mot : chien, Classe : nom, Fonction : sujet

ex : J'ai un chien.
Mot : chien, Classe : nom, Fonction : complément

Les classes de mots :

le nom : il y a des noms communs et des noms propres. Ils désignent un objet ou une personne. (chien, homme, Paris, ...)
le déterminant : il introduit un nom, peut être démonstratif, possessif, être un article. (le, la, ce, mon, ...)
l'adjectif : il donne des renseignements sur le nom qu'il accompagne. (rouge, gentil, ...)
le pronom : il remplace un nom ou un G.N. (je, tu, lui, ...)
le verbe : c'est le mot qui exprime l'action ou l'état du sujet. (manger, être, avoir, ...)
l'adverbe : c'est un mot invariable qui modifie le sens d'un autre mot ou d'une phrase (vite, beaucoup, ...)
la préposition : c'est un mot invariable qui unit un complément au mot qu'il complète. (à, de, pour, ...)
la conjonction : elle unit deux mots ou groupes de mots. (et, ou, mais, ...)
l'interjection : c'est une exclamation brève qui exprime un sentiment. (ah! oh! ...) Retour au CM1/CM2
