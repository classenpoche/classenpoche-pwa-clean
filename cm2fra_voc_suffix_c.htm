Vocabulaire "Les suffixes " Le suffixe est un élément placé à la fin d'un mot, après le radical.
En ajoutant un suffixe sur un mot simple on forme un mot dérivé.
Ce nouveau mot n'a pas le même sens mais il est de la même famille de mot que le mot de départ. ex : renard + eau = renardeau (petit renard)
radical + suffixe = mot dérivé ex : boucher + ie = boucherie

radical + suffixe = mot dérivé Souvent le radical ne se trouve pas entier dans le mot dérivé. ex :
soupe; soup-ière
lumière; lumi-neux

Dans les mots dérivés, le radical exprime l'idée, les suffixes qu'on y ajoute modifient cette idée pour en exprimer les nuances.
En connaissant le sens des suffixes on peut mieux comprendre les nouveaux mots ainsi créés.

Le suffixe "ette" signifie petit. Tous les mots formés avec ce suffixe indique quelquechose ou quelqu'un plus petit que le mot d'origine.
ex : fille, fillette (petite fille) ; maison, maisonnette (petite maison) ...

Tu peux trouver les sens de tous les préfixes et suffixes au début du dictionnaire.
