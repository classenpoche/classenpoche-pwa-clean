"La ponctuation" Les principaux signes de ponctuation sont :

Le point .
Il indique la fin d'une phrase déclarative ou impérative.

La virgule ,
Elle marque une pause de courte durée dans une phrase, permet une juxtaposition.

Le point virgule ;
Il marque une pause de plus longue durée dans une phrase, il permet aussi une juxtaposition.

Les deux points :
Ils annoncent une énumération ou le début d'un dialogue.

Les trois points de suspension ...
En fin de phrase ils laissent imaginer une suite, à l'intérieur d'une phrase ils indiquent une hésitation.

Le point d’interrogation ?
Il indique la fin d'une phrase interrogative.

Le point d’exclamation !
Il indique la fin d'une phrase exclamative.

Les parenthèses ( )
Elles permettent d'isoler un mot ou un groupe de mots.

Les guillemets « »
On les ouvre au début d'un dialogue et on les ferme à la fin.

Le tiret -
Il indique le changement d'interlocuteur dans un dialogue.
