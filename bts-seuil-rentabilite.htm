SEUIL DE RENTABILITé

Dans les calculs de seuil de rentabilité, les CHARGES FIXES sont toujours connues. Ou bien elle sont données comme telles (par exemple "le montant des charges fixes est de 45 000 euros") ou bien on donne tous les éléments pour les calculer.
Rappels de définition :

- les charges fixes sont des charges que l'entreprise doit supporter quel que soit le niveau de son activité.
- le résultat est égal à la différence entre la marge sur coût variable et les charges fixes : R = MCV - CF Cela signifie que pour que le seuil de rentabilité soit atteint, il faut que MCV = CF
Il y a trois méthodes permettant de calculer le seuil de rentabilité.
Connaissant toujours les charges fixes il faut choisir la méthode selon les informations dont on dispose :
 On connait (ou on peut calculer) le chiffre d'affaires (CA) et la Marge sur Coût Variable globale (MCV) On connait (ou on peut calculer) le prix de vente unitaire (pvu) et le coût variable unitaire (cvu)
ou la marge sur coût variable unitaire (mcvu) On connait (ou on peut calculer) le taux de marge sur coût variable (tmcv)
tmcv = 100% - tcv
(tcv = taux de charges variables)
SR (valeur) = CA X CF / MCV
SR (quantité) = CF / (pvu - cvu) ou
SR (quantité) = CF / mcvu
SR (valeur) = CF / tmcv
