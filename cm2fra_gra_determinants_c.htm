"Les déterminants"
Qu'est-ce qu'un déterminant?
Le déterminant accompagne le nom. Il est devant le nom.
Il nous permet de connaître le genre et le nombre du nom qu'il accompagne.
Ex.:
Un jeu (Nom masculin singulier.)
Cette fléchette (Nom féminin singulier.)
Les souris (Nom féminin pluriel.)
Quelques nuages (Nom masculin pluriel.) Les différentes sortes de déterminants.
Il existe deux sortes de déterminants : les articles (le, la, l', les, un, une, des...) et les adjectifs non qualificatifs (ma, ton, deux, plusieurs, cette,...).
Les déterminants les plus utilisés sont les articles.
Certains déterminants indiquent la possession : mon, ma, tes, ses...
Ex. : Ma trousse, ton cartable, tes chaussures,....
D'autres déterminants indiquent ce que l'on veut désigner en particulier (ce, cette, ces...).
Ex. : Ce clavier, cette souris. Comment ne pas confondre les déterminants et les pronoms?

Il ne faut pas confondre les déterminants et les pronoms qui parfois se ressemblent beaucoup.
Un déterminant accompagne un nom en précisant son genre et son nombre alors qu'un pronom remplace un nom ou un groupe nominal pour éviter de le répéter.
Ex. : Ho la belle pomme, je vais la manger!.
Dans cette phrase, le premier la est un déterminant, il accompagne pomme (notons qu'on peut trouver un adjectif qualificatif entre les deux) et nous indique que ce nom est au féminin singulier. Le deuxième la remplace le nom pomme pour éviter de le répéter. Retour au CM1/CM2
