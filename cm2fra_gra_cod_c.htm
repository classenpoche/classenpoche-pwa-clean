" Le C.O.D."

Le complément d'objet direct (C.O.D.) est un groupe de mots ou un mot dans une phrase .
On le trouve le plus souvent juste après le verbe.
Le C.O.D. permet de compléter la phrase pour donner un sens. On le trouve en se posant la question qui ? ou quoi ? juste après le verbe. Exemple : L'élève fait des multiplications. L'élève fait (quoi?) des multiplications. Exemple : L'élève rencontre la maîtresse. L'élève rencontre (qui?) la maîtresse. Le complément d'objet peut être :

un groupe nominal :
ex : Le vent disperse les graines légères.

un nom propre :
ex : j'ai vu Victor. un pronom :
ex : je l'ai vu. un infinitif
ex : Elle aime bavarder. une proposition :
ex : Elle promet qu'elle viendra bientôt.

Dans certaine phrase il n'y a pas de C.O.D.
Exemple : Le hamster joue dans sa cage.
On ne peut pas poser la question: Le hamster joue (quoi?)
