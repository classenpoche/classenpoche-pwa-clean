Grammaire "Les adjectifs qualificatifs" L'adjectif qualificatif est un mot qui complète un nom ou un pronom. Il donne des renseignements supplémentaires.
ex : Le petit chien noir. Il s'accorde en genre (féminin, masculin) et en nombre (singulier, pluriel) avec le nom ou le pronom qu'il qualifie même s'il en est éloigné.
ex : Les petites chiennes, après s'être roulées dans le charbon, étaient toutes noires.

Les fonctions de l'adjectif qualificatif sont généralement :

- épithète du nom.
Il est dans le groupe nominal à coté du nom.
ex : Les touristes anglais achètent des souvenirs. - attribut du sujet.
Il est séparé du nom qu'il qualifie par un verbe d'état (être, paraître, sembler, devenir, demeurer, avoir l'air)
ex : Cette pomme semble verte.

Attention :

L'adjectif devient un nom lorsqu'il est employé seul avec un déterminant.
ex : Un petit est venu dans notre classe.

L'adjectif peut être employé comme adverbe.
ex : Quand le temps est clair, (adjectif), j'y vois clair. (adverbe ) Retour au CM1/CM2
