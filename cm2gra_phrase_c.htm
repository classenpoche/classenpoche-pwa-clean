" La phrase"
Définition : une phrase une suite de mots ayant un sens.
Il y a 4 Types de phrases :
déclarative : Je viens.
interrogative : Viendras-tu?
exclamative : J'arrive!
impérative : Viens ici.
Il y a 2 formes de phrases :
affirmative : Je viens.
négative : Je ne viens pas.
Organisation : Dans une phrase les mots sont organisés en groupes.
Le Groupe Sujet est celui qui fait l'action. On peut l'encadrer par " c'est...qui ".
Le Groupe Verbal peut se réduire au Verbe seul, mais il est souvent accompagné d'un Complément d'Objet.
Ex : Mon frère mange le chocolat.
C'est mon frère qui mange le chocolat.
G.S. : Mon frère
G.V. : mange le chocolat.
Enfin, un autre groupe de mots appelé Complément Circonstanciel peut donner des renseignements sur le temps, le lieu, la manière,...
Ex : Aujourd'hui, mon frère mange le chocolat avec une cuillère, dans la cuisine.
C.C. de temps (quand ?) : Aujourd'hui
C.C. de manière (comment ?) : avec une cuillère
C.C. de lieu (où ?) : dans la cuisine. Retour
