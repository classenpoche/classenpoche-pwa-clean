Le calcul littéral :

Il correspond a une partie essentielle des mathématiques car on manipule des calculs dans lesquels figurent une ou plusieurs variables (notées x, y ou a etc... le plus souvent). L'intérêt de savoir manipuler ces calculs est de pouvoir faire les calculs une seule fois puis d'utiliser les résultats simplifiés lorsque l'on connaît la valeur de x. Règles :
- Il ne faut pas oublier que dans une expression, chaque lettre désigne un nombre connu ou inconnu.
On peut donc calculer la valeur d'une expression pour une valeur donnée à chaque variable.

Par exemple :
" Calculer 3x+2 pour x=10"
on fait :
3x+2= (3 *10) + 2
on remplace:
3x+2= 30 + 2 = 32 1 - On peut supprimer le signe *devant une lettre désignant un nombre ou une parenthèse. Ainsi : 4 *y = 4y
et : 4(y + 5 ) = 4 *(y+ 5) = 4y + 20 2 - On peut additionner 4y + 7y =11y, mais on ne peut pas additionner 4 y + 7 !

De même on peut additionner: 4y²z+5y²z = 9y²z

mais pas 4y²z+5yz !! 3 - Développement, factorisation, identités remarquables: De la gauche vers la droite on développe : on transforme un produit en somme.
Cela peut aider pour faire des multiplications de tête:
( 101 *63 ou 99 *78) De la droite vers la gauche, on factorise : on transforme une somme en un produit.
Cela sert à résoudre certaines équations en 3ième. k ( x + y) = kx + ky

k ( x - y) = kx - ky ( a + b ) (c + d) = ac + ad + bc + bd ( a + b )² = a² + 2ab + b²
( a - b )² = a² - 2ab + b²
( a + b ) ( a - b) = a² - b²
