Conjugaison

Le mode de conjugaison d'un verbe" Le mode, le temps et la personne déterminent chacune des formes que peut prendre un verbe.
Chacun de ses modes est subdivisé en temps.
Le mode des verbes Les verbes se conjuguent à quatre modes : - Le mode indicatif (présent, futur, imparfait, passé composé) qui exprime des faits réels :
ex : Tu arrives demain. - Le mode impératif qui permet de donner des ordres ou des conseils :
ex : Arrive demain ! - Le mode conditionnel qui exprime des fait qui dépendent d'une condition ( le verbe suivant si étant à l' imparfait ) : ex : S'il faisait beau (Imparfait), j'arriverais demain.(conditionnel) - Le mode subjonctif qui indique une incertitude, une possibilité, exprime un souhait, une volonté ou un conseil.
ex : Il se peut que nous arrivions demain.(subjonctif)
