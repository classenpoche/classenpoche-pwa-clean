Nombres relatifs:
Comparaisons de deux nombres relatifs:

On peut graduer une droite avec des nombres relatifs.
Il est alors facile de comparer deux nombres relatifs.
Comparaison de deux nombres de même signe:
Ex. : 2 < 5 ; -5 < -2.
Comparaison de deux nombres de signes contraires:
Ex. : -2 < 5 ; -5 < 2 : le plus petit est le négatif. Addition: Somme de deux nombres de même signe:
Ex. : (+5) + (+3) = +8 ; (-5) + (-3) = -8.
Somme de deux nombres de signes contraires:
Ex. : (+5) + (-3) = +2 ; (-5) + (+3) = -2.
Opposés: Deux nombres relatifs sont opposés si leur somme est égale à zéro. Ex. -2 est l'opposé de 2 ; 3 est l'opposé de -3.

Soustraction :
Pour soustraire on ajoute l'opposé. Ex. : (+5) - (+3) = (+5) + (-3) = 2.
(+5) - (-3) = (+5) + (+3) = 8.

Multiplication et division
Règle des signes + par + donne +
- par - donne +
+ par - donne -
Exemples:
2,1 x 3 = 6,3
2,1 x (-3) = -6,3
(-2,1) x (-3) = 6,3
(-2,1) x 3 = -6,3
3 / 4 = 0,75
3 / (-4) = -0,75
(-3) / (-4) = 0,75
(-3) / 4 = -0,75 Remarque:
La multiplication par 0 donne 0.
